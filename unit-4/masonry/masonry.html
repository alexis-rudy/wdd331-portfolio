CSS Grid layout lesson

Masonry with CSS Grid

Compare a regular grid with a row-spanning grid that packs variable-height cards into the available space.

The problem

Standard CSS Grid leaves gaps

Each row is sized by its tallest card, so shorter cards cannot move up into the empty space below them.

The CSS Grid approach

Pack cards with row spans

A small auto-row creates the masonry rhythm. Each card spans the number of rows needed for its content.

01

Short card

One line of content.

02

Tall card

This card spans more grid rows, allowing the next card in its column to start as soon as the space is available.

03

Medium card

It occupies only the rows its content needs.

04

This card packs below the first one.

05

Another card

Explicit spans keep the layout responsive and gap-free.

grid-row: span var(--row-span)

The JavaScript approach

Measure cards at runtime

JavaScript reads each card's height and calculates the exact row span. Resize the browser to see the layout recalculate.

Responsive result

Its span updates when the column width changes.

04

One calculation

The browser does not need hard-coded content sizes.

05

New content

Add or edit content and the ResizeObserver recalculates the placement.

grid-row: span calculateRows(card)

Teaching point: CSS Grid does not automatically create masonry in this pattern. The CSS example uses deliberate spans, while the JavaScript example measures each card and calculates those spans whenever its size changes.
